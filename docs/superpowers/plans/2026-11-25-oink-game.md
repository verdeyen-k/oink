# Oink Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play Oink against the computer: Pig Barn with merging, and the Classic, Marathon and Mega Boar modes with real-time top-down fights.

**Architecture:** Logic with no drawing in `rules.js` (barn, damage, attacks, Marathon), `battle.js` (fight simulation stepped by `step(state, dt, inputs)`) and `ai.js` (computer inputs). All three run in Node for tests. `game.js` draws on a canvas and handles screens and controls.

**Tech Stack:** Plain HTML + JS, canvas 2D, Fredoka, `node --test`.

**Spec:** `oink/docs/superpowers/specs/2026-11-25-oink-game-design.md` (plus `2026-11-24-oink-design.md` for elements/merging)

## Global Constraints
- Same UMD pattern as `elements.js` (`window.OinkRules`, `window.OinkBattle`, `window.OinkAI`; `module.exports` in Node).
- The attack numbers come from the spec's table exactly. Health 100 / Mega Boar 300; speed 180 / 140; arena 960×600; round limit 90 s.
- Levels: `['veryeasy','easy','medium','hard','insane']`, shown as Very Easy, Easy, Medium, Hard, Insane.
- Save key `localStorage['oink-save-v1']`.
- Randomness always comes in as an `rng` function so tests can be repeated.

## Review Focus
1. Saved barn missing or broken: start fresh with the 9 pigs, no crash.
2. A merge that would leave fewer than 3 pigs, or make nothing new, is refused with a message.
3. Projectiles that leave the arena or hit rocks disappear (no endless growth).
4. Both pigs reaching 0 health on the same step: the one with more health left (or a replay) decides it, never "both win".
5. Marathon with an odd number of racers: one sits out each round and nobody gets stuck.

### Task 1: Rules (`rules.js`)
**Files:** create `oink/rules.js`, `oink/tests/rules.test.js`.
**Produces:**
- `LEVELS`, `LEVEL_NAMES`
- `ATTACKS: {[elementId]: {name, speed, damage, every, reach, radius, slow?, root?, push?, homing?}}`
- `damageMult(attackEl, defenderEls: string[]) -> number`
- `newBarn() -> {nextId, pigs: [{id, key}]}` (the 9 singles)
- `mergeResult(barn, idA, idB) -> {ok: true, key} | {ok: false, why: string}`; `merge(barn, idA, idB) -> barn` (new object)
- `rewardPig(barn, rng) -> {barn, key}`
- `loadBarn(text|null) -> barn` (falls back to `newBarn()`)
- `megaElements(keys: string[]) -> string[]` (union, in element order)
- `computerTeam(level, playerKeys, rng) -> string[3]`
- `pairUp(racerIds, rng) -> {pairs: [[a,b]], sitOut: id|null}`
- `quickWinChance(keyA, keyB) -> number` (0..1, from the damage multipliers)
- Tests: fire beats ice ×2; ice vs fire ×0.5; fire vs ice+plant ×2; fire vs ice+water ×1; common ×1; newBarn has 9; merge fire+water ok; fire+water with plant refused; fire+water with water refused; merging with 3 pigs left refused; loadBarn('junk') = fresh; pairUp 5 racers → 2 pairs + 1 sitting out, everyone once; megaElements(['fire+water','fire','ice']) = fire, ice, water.

### Task 2: Battle + computer (`battle.js`, `ai.js`)
**Files:** create `oink/battle.js`, `oink/ai.js`, `oink/tests/battle.test.js`.
**Produces:**
- `createBattle({a: {key, elements, mega?}, b: {...}}, rng) -> state` with `state.pigs[0|1] = {x,y,hp,maxHp,r,speed,elements,el,cool,slowT,rootT,vx,vy,face,attackT}`, `state.shots`, `state.rocks`, `state.time`, `state.winner` (null/0/1/'draw')
- `step(state, dt, inputs: [{mx,my,aimX,aimY,attack,switchEl}, …])`: moves (blocked by rocks and walls), switches element (on the press), fires if the cooldown is ready, moves shots, homes, hits (damage × mult, effects), removes dead shots, sets the winner.
- `OinkAI.input(state, me, level, rng, memory) -> input`
- Tests: a shot at a still enemy hits and does `10 * damageMult`; ice slows; vine roots; shots die on rocks and at the edge; same-step KO → the higher hp left wins; timeout at 90 s → higher share wins; switchEl cycles the elements; **insane beats veryeasy at least 8 of 10** in full simulated battles (dt 1/30).
